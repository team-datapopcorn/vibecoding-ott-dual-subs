# OTT 이중자막 (Dual Subs) Privacy Policy

Last updated: 2026-04-05

OTT 이중자막 (Dual Subs) is a Chrome extension that displays Korean and English subtitles together on supported OTT services, currently Netflix and Coupang Play.

## 1. What this extension does

The extension:

- detects subtitle resources requested by supported OTT services
- displays Korean and English subtitles together on the video player
- lets the user adjust subtitle size, color, and position
- lets the user download detected subtitle files in supported formats

## 2. What data is processed

To provide its core functionality, the extension may process the following information locally in the user's browser:

- the current tab URL to determine whether the page is a supported OTT playback page
- subtitle resource URLs requested by the supported OTT service
- subtitle text/content retrieved directly from the supported OTT service in order to render dual subtitles or download subtitle files
- user-selected subtitle preferences such as font size, subtitle color, and subtitle position

## 3. What data is collected or shared

This extension does not operate its own backend server and does not intentionally collect, sell, or transfer user data to the developer or to third parties.

Specifically:

- no personal account information is collected by the developer
- no analytics, advertising, or tracking SDKs are used
- no subtitle content or browsing data is transmitted to a developer-controlled server
- no user data is sold or shared with third parties for unrelated purposes

## 4. Local storage

The extension may store the following information locally in the browser so the extension can function correctly:

- detected subtitle session state for the active tab
- supported platform state for the active tab
- subtitle display preferences selected by the user

This information is used only to provide the extension's requested features and is not used for profiling, advertising, or unrelated analytics.

## 5. Chrome permissions

The extension requests certain Chrome permissions only to support its core subtitle features:

- `webRequest`: to detect subtitle file requests from supported OTT services
- `tabs`: to identify supported playback tabs and communicate with the active tab
- `storage`: to keep subtitle-related state and user preferences locally in the browser
- host permissions for supported OTT domains: to run on supported playback pages and process subtitle resources for those services

## 6. Third-party services

The extension interacts only with the supported OTT websites the user chooses to open. Subtitle resources are requested directly from those services as part of the normal extension flow.

## 7. Changes to this policy

If this privacy policy changes, the updated version will be published at a new revision date.

## 8. Contact

For privacy or support questions, contact:

- dev@datapopcorn.ai

# OTT 이중자막 (Dual Subs) 개인정보처리방침

최종 업데이트일: 2026-04-05

OTT 이중자막 (Dual Subs)는 넷플릭스와 쿠팡플레이 같은 지원 OTT 서비스에서 한국어와 영어 자막을 동시에 표시하는 Chrome 확장 프로그램입니다.

## 1. 확장 프로그램의 기능

이 확장 프로그램은 다음 기능을 제공합니다.

- 지원 OTT 서비스가 요청하는 자막 리소스를 감지
- 영상 플레이어 위에 한국어와 영어 자막을 동시에 표시
- 자막 크기, 색상, 위치를 사용자가 조정
- 감지된 자막 파일을 지원 형식으로 다운로드

## 2. 처리하는 정보

확장 프로그램의 핵심 기능을 제공하기 위해, 사용자의 브라우저 안에서 다음 정보가 로컬로 처리될 수 있습니다.

- 현재 탭 URL: 지원되는 OTT 재생 페이지인지 확인하기 위해 사용
- 지원 OTT 서비스가 요청한 자막 리소스 URL
- 이중 자막 표시 또는 자막 파일 다운로드를 위해 지원 OTT 서비스로부터 직접 가져온 자막 텍스트/콘텐츠
- 사용자가 선택한 자막 설정 값(글자 크기, 색상, 위치 등)

## 3. 수집 및 제3자 제공 여부

이 확장 프로그램은 개발자 자체 서버를 운영하지 않으며, 개발자 또는 제3자에게 사용자 데이터를 의도적으로 수집, 판매, 이전하지 않습니다.

구체적으로:

- 개발자가 사용자의 계정 정보나 개인식별정보를 수집하지 않습니다.
- 분석, 광고, 추적 SDK를 사용하지 않습니다.
- 자막 콘텐츠나 브라우징 데이터를 개발자 서버로 전송하지 않습니다.
- 사용자 데이터를 확장 프로그램의 목적과 무관하게 제3자에게 판매하거나 공유하지 않습니다.

## 4. 브라우저 로컬 저장

다음 정보는 확장 프로그램 기능 제공을 위해 브라우저에 로컬 저장될 수 있습니다.

- 현재 탭의 자막 세션 상태
- 현재 탭의 지원 플랫폼 상태
- 사용자가 선택한 자막 표시 설정

이 정보는 확장 프로그램 기능 제공에만 사용되며, 광고, 프로파일링, 무관한 분석 목적으로 사용되지 않습니다.

## 5. Chrome 권한 사용 목적

확장 프로그램은 핵심 자막 기능 제공을 위해서만 다음 권한을 사용합니다.

- `webRequest`: 지원 OTT 서비스의 자막 파일 요청을 감지하기 위해 사용
- `tabs`: 현재 활성 탭이 지원 재생 페이지인지 확인하고 콘텐츠 스크립트와 통신하기 위해 사용
- `storage`: 자막 관련 상태와 사용자 설정을 브라우저에 로컬 저장하기 위해 사용
- 지원 OTT 도메인에 대한 host permissions: 지원 페이지에서 실행되고 해당 서비스의 자막 리소스를 처리하기 위해 사용

## 6. 제3자 서비스

이 확장 프로그램은 사용자가 직접 연 지원 OTT 웹사이트와만 상호작용합니다. 자막 리소스는 확장 프로그램 기능 수행 과정에서 해당 OTT 서비스로부터 직접 요청됩니다.
